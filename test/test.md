## Markdown Features

- **Bold text**
- *Italic text*
- `inline code`
- [A link](https://example.com)

> Blockquotes and code blocks are supported.

## LaTeX Features

Inline math: $E = mc^2$

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

$$
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$
