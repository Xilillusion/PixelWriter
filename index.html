Small tools.
Sharp pixels.

A focused collection of lightweight, local-first tools for turning text, PDF pages, and Markdown into downloadable PNG images.

TXT

TXT to pixel PNG

Convert ASCII text into a crisp black-and-white or grayscale PNG using a built-in 5×7 bitmap or a system monospace font with adjustable cell dimensions.

Open tool
PDF

PDF to PNG

Render selected PDF pages as a vertically or horizontally stitched PNG with adjustable scale, black-and-white, grayscale, or limited-color output, and optional compressed rendering.

Open tool
MD

MD to PNG

Render Markdown with headings, lists, links, blockquotes, code blocks, and LaTeX equations into a downloadable PNG with page size, orientation, columns, proportional font-size, font, scale, color, and compression controls.

Open tool
